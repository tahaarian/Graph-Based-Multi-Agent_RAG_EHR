# پوشه داده (data/)

این پوشه میزبان داده‌های بنچمارک **EHRSHOT** است:
https://github.com/som-shahlab/ehrshot-benchmark/

- **`raw/`**: فایل‌های CSV خام و **دست‌نخورده** طرح **OMOP CDM v5.4** که مستقیماً دانلود می‌شوند. این پوشه هرگز تغییری نمی‌کند و باید دقیقاً مطابق خروجی رسمی بنچمارک بماند.
- **`processed/`**: داده‌های پاک‌سازی‌شده و نگاشت‌شده به اسکیمای داخلی پروژه (فاز ۱ به بعد).
- **`external/`**: داده‌های کمکی مانند واژگان و فرهنگ‌های داده.

⚠️ **نکته مهم:** داده‌های خام به دلیل **ملاحظات حریم خصوصی بیماران** و **حجم بالا** هرگز نباید به git کامیت شوند؛ این موضوع در `.gitignore` پوشش داده شده است (الگوهای `data/raw/*` با نگه‌داشتن `.gitkeep`).
